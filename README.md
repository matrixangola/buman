# B.Uman™

**Menos burocracia. Menos peso. Mais espaço para ti.**

Landing page + chatbot de marcação da B.Uman — by Eli Colles.

## Stack
- HTML5, CSS3, JavaScript vanilla
- Sem frameworks, sem build step

## Estrutura
- `index.html` — página principal
- `css/` — estilos divididos por responsabilidade
- `js/` — `main.js` (nav/reveal), `faq.js` (accordion), `btalk.js` (chatbot)
